# Full-stack Museum

A virtual museum built with code, featuring 26 interactive exhibits. Frontend: HTML/CSS/JS. Backend: Flask + SQLite. Includes an AI docent.

**Live demo:** https://lio.pythonanywhere.com/

## Features

5 halls, 26 exhibits:

- **Basics**: text toggle, background color, hyperlink
- **Styles**: input display, image, font size up/down, dark mode
- **Tools**: todo list, audio player, back to top, login, password strength checker, countdown timer
- **Fun**: timer, random picker, char counter, typing speed test, random food picker
- **Smart**: copy to clipboard, random quote, visit counter, guess the number, Beijing weather, student data, random password generator

Extras:

- AI docent "Xiaodao" (Agnes API)
- Rubber duck (20 replies)
- Floating theme toggle
- Like panel (26 exhibits)

## Tech Stack

- **Frontend**: HTML / CSS / JavaScript (vanilla, no framework)
- **Backend**: Flask + Flask-CORS
- **Database**: SQLite
- **AI**: Agnes API (`agnes-2.0-flash`)
- **External API**: open-meteo (Beijing weather)
- **Storage**: localStorage (visit count, theme)
- **Deployment**: PythonAnywhere
